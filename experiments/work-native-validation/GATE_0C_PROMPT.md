# Gate 0C — Persistent Councillor State Test

Use the prompt from the project conversation that tests persistent councillor identity with disposable delegated workers.

Core hypothesis:

> A councillor is a persistent strategic identity and position state, not a persistent runtime process.

The test must verify both continuity and updateability:

- fresh workers must not drift from prior councillor state without a causal reason;
- fresh workers must be allowed to change the councillor's position when genuinely new arguments defeat or modify the existing rationale;
- every position change must identify the new argument, the prior rationale it changes, and why the revision remains consistent with the councillor's value matrix.

The Seneschal must persist councillor state between rounds and supply that state to fresh delegated workers.
