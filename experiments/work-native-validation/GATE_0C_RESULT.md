# Gate 0C Result — Persistent Councillor State with Disposable Workers

## Result

**PASS for continuity and state rehydration. Recommendation reversal / causal-bridge transition: NOT DEMONSTRATED.**

The experiment completed all six phases using 20 fresh, disposable delegated workers. No final Council recommendation or vote was created.

## Capability assessment

| Capability | Status | Evidence |
| --- | --- | --- |
| Fresh delegates rehydrated each councillor from stored state | PASS | Each subsequent phase used newly created workers with written state only. |
| No unexplained drift in no-new-information control | PASS | All four retained C in Phase 2. |
| Value matrices remained behaviorally visible | PASS | Architect stressed architecture/options; Vanguard timing/traction; Steward capacity; Castellan containment. |
| Original positions remained immutable baselines | PASS | Each state retained its Phase 1 recommendation: C. |
| Current state could evolve separately from original | PASS | Rationale, accepted arguments, safeguards, and conditions evolved while original recommendations stayed fixed. |
| Cross-councillor arguments could cause justified state refinement | PASS | Phase 3–4 added durable gates: standardization, isolation, review, rollback, and support caps. |
| Recommendation changes included explicit causal bridges | NOT DEMONSTRATED | No recommendation changed, so the causal-bridge mechanism for recommendation reversal was never exercised. |
| Fresh workers preserved prior concessions/revisions | PASS | Later delegates retained accumulated safety, capacity, and containment constraints. |
| New evidence caused rational reconsideration | PASS | All four materially updated feasibility and risk judgments after Phase 5. |
| State did not make councillors artificially stubborn | PASS | All accepted that architecture, support, and severe-failure concerns had materially weakened. |
| Councillors remained distinct without persistent runtime sessions | PASS | Reasoning remained recognizably differentiated across fresh workers. |
| Multi-round Council reasoning remained coherent | PASS | Later responses consistently preserved the pilot's guardrails and unresolved questions. |

## Findings

1. No councillor changed recommendation during the no-new-information control.
2. Fresh workers treated stored current judgment as the continuation point rather than independently rerunning the decision.
3. No councillor changed recommendation after disclosure, but all four accepted and preserved additional constraints from peers.
4. No recommendation-level causal bridge was required because no recommendation changed.
5. New evidence materially revised all four councillors' rationale and feasibility/risk judgments while strengthening rather than defeating C.
6. No councillor showed artificial stubbornness; all incorporated evidence that weakened their earlier concerns.
7. No fresh worker reverted an earlier refinement or concession without justification.
8. Persistent values remained visible in why each councillor accepted or rejected new information.

## Interpretation

This experiment provides strong evidence for the revised architecture:

> **A councillor can be represented as persistent strategic identity + persistent position state, while the delegated reasoning worker is disposable.**

The test demonstrated continuity against stochastic drift and evidence-responsive updating without requiring persistent runtime subagent sessions.

It did **not** demonstrate recommendation reversal. That capability remains an untested path, not a failed capability.

A focused follow-up should introduce new evidence that materially defeats one or more councillors' current recommendation and verify that fresh workers can cross from the stored recommendation to a new recommendation through an explicit causal bridge.
