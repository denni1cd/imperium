# Council Profiles

This directory will contain the persistent strategic profiles of the initial Imperial Council.

Profiles are intentionally **not yet defined**. The manifesto and project plan require the shared strategic value vocabulary to be approved first so that member differences arise from a common, inspectable set of strategic values rather than ad hoc character design.

Each eventual profile should contain only information that materially changes reasoning, such as:

- mandate;
- value matrix whose weights sum to `1.0`;
- strategic priorities and tradeoffs;
- characteristic blind spots;
- risk tolerance;
- temporal orientation;
- evidence/update rules;
- concise communication tendencies only where behaviorally useful.

Universal requirements such as truthfulness, intellectual honesty, willingness to update, and obedience to the Sovereign's stated objective are not competing personality values.

Avoid elaborate lore. Personality supports cognitive identity; it does not substitute for it.
