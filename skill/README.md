# Imperial Council Skill

This directory is the future behavior package for the Work-native Imperial Council.

The Skill itself is **not implemented yet**. Gate 0 must first demonstrate that ChatGPT Work can reliably provide the required delegation and information-boundary behavior.

The durable references in `references/` define accepted behavior independently of any final Skill syntax or packaging.

Planned references:

- `DELIBERATION_PROTOCOL.md` — accepted Council lifecycle.
- `OUTPUT_CONTRACT.md` — required definitive final result.
- `WORK_EXECUTION_RULES.md` — native Work delegation and visibility constraints.
- `VALUE_VOCABULARY.md` — to be created after design review.
- `COUNCIL_PROFILES.md` or direct references to `council/*.md` — after profiles are approved.

Once Gate 0 passes, `SKILL.md` should be created as a concise coordinator that references these durable documents rather than duplicating them.
